# Simple Calculator

这是一个使用 HTML、CSS 和 JavaScript 实现的简单计算器示例。

演示：

![screenshot](screenshot.png)

功能：
- 点击按钮或使用键盘输入数字和运算符
- 支持小数点、括号、删除（Backspace）、清除（Esc 或 C）和回车计算

如何运行：
1. 克隆仓库：
   ```bash
   git clone https://github.com/yumeizhou1/foxmail-git-test.git
   cd foxmail-git-test
   ```
2. 本地打开：
   直接在浏览器中打开 `index.html` 即可运行。

GitHub Pages 自动部署：
- 我添加了一个 GitHub Actions 工作流，会在每次 push 到 `main` 分支时将仓库内容发布到 `gh-pages` 分支，从而可以启用 GitHub Pages 来托管网站。
- 页面地址（启用后）： `https://yumeizhou1.github.io/foxmail-git-test/`
